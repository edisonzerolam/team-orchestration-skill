# 税率与政策参考（配套知识模板）

> ⚠️ 本文件为 tax-compliance-team 的配套知识模板，内容为通用框架示例。
> 税率、扣除限额、优惠政策以最新《中华人民共和国企业所得税法》《增值税暂行条例》及现行税法为准；
> 正式交付前请团队负责人按最新法规与客户实际税种校准。

## 增值税（VAT）

| 税率 | 适用范围 | 备注 |
|------|----------|------|
| 13% | 销售货物、加工修理修配、有形动产租赁 | 一般计税方法 |
| 9%  | 交通运输、建筑、不动产租赁/销售、基础通信、农产品等 | |
| 6%  | 现代服务、生活服务、金融服务、无形资产（除不动产） | |
| 0%  | 出口货物、跨境应税行为（符合退免税政策） | |
| 3%（征收率） | 小规模纳税人 | 可享小微免征优惠 |

## 企业所得税

- 基本税率 25%
- 符合条件的小型微利企业：减按 20% 税率，并享所得额减计优惠
- 高新技术企业：15%

## 附加税费（以增值税/消费税为基数）

- 城建税：7%（市区）/ 5%（县城、镇）/ 1%（其他）
- 教育费附加：3%
- 地方教育附加：2%

## 个人所得税（综合所得）

- 适用 3%–45% 七级超额累进税率（年度汇算）
- 经营所得 5%–35% 五级超额累进

## 常用优惠/扣除提示

- 小微企业增值税起征点、六税两费减半等政策随年度调整，需动态核实。
- 专项附加扣除（子女教育、房贷利息、赡养老人等）以最新标准为准。

> 注：本表为分类框架，具体税目、税率及优惠以主管税务机关最新公告为准。
