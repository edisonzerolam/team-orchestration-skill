# RUM 常见查询（common_queries）

> 本文件为 rum-fullstack-team 的配套知识模板，列出前端/客户端性能监控（RUM）常见查询场景与维度。
> 与 `@skills/tencent-cloud-rum-zh-2.1/SKILL.md` 配合使用；正式查询语法以所用监控平台为准。

## 常见查询场景

| 场景 | 关注指标 | 常用维度 |
|------|----------|----------|
| 页面加载性能 | FCP / LCP / Load 时长、白屏 | 页面、地区、设备、网络 |
| JS 错误 | 错误率、错误次数、影响用户 | 页面、错误类型、浏览器 |
| 接口请求 | API 成功率、耗时、失败码 | 接口、地域、版本 |
| 卡顿/卡死 | FPS、长任务、ANR | 页面、机型、系统版本 |
| 资源加载 | 资源错误、耗时 | 资源类型、域名 |
| 留存/转化 | PV / UV、关键路径转化 | 渠道、时段 |

## 常用分析维度

- 时间范围（实时 / 近 24h / 自定义）
- 分组（group by）：页面、地域、运营商、设备型号、系统版本、浏览器、JS SDK 版本
- 过滤（filter）：错误码、网络类型、是否首访

## 分析流程建议

1. 先按"错误率 / 耗时"排序定位 Top 页面或接口；
2. 按设备 / 系统 / 网络维度下钻，区分"普遍问题"还是"特定环境"问题；
3. 结合源码版本与发布时间点，关联回归。

> 注：具体字段名与查询语法以所接入的 RUM 平台文档为准。
