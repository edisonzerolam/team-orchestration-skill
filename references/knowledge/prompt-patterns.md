# Prompt 模式库

## 举证阶段 Prompt 模式

### 模式 1：结论先行型
```
你是{role}。议题：{issue}。
请先给出你的核心结论（1-2句），再逐条列出支撑依据。
每条依据格式：| # | 依据 | 来源 | 可信度(A/B/C/D) |
```

### 模式 2：对抗举证型
```
你是{role}。议题：{issue}。
假设对方持完全相反立场，请：
1. 列出支持你立场的最强3条证据
2. 预判对方最可能的3条反驳
3. 对每条预判反驳准备回应
```

### 模式 3：数据驱动型
```
你是{role}。议题：{issue}。
请聚焦可量化数据：
- 关键指标及其当前值/历史分位
- 数据来源与更新时间
- 数据局限性说明
```

## 质证阶段 Prompt 模式

### 模式 4：逐条质证型
```
以下是对方产物。请逐条：
1. 标注[可信]/[存疑]/[错误]
2. 对[存疑]和[错误]给出理由
3. 补充对方遗漏的关键点
```

### 模式 5：立场修正型
```
基于对方质证意见，请：
1. 撤回站不住的主张（标注[撤回]）
2. 加强可坚守的主张（补充新证据）
3. 修正表述不严谨之处
4. 给出修正后的终局立场
```

## 终审阶段 Prompt 模式

### 模式 6：裁决合成型
```
你是审判长。各方已提交终局立场。请：
1. 逐争点裁决（采信/部分采信/排除）
2. 标注裁决理由与依据来源
3. 对存疑事项如实标注
4. 给出整体置信度(0-1)
```

### 模式 7：行动导向型
```
基于裁决结论，请输出：
1. 核心结论（3句以内）
2. 行动建议（按优先级排序）
3. 风险提示（概率+影响）
4. 后续跟踪事项
```
