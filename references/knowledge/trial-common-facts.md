# 审判庭通用事实知识 — 举证标准与质证要点

## 举证标准

### 事实类争点
- 需至少两个独立来源交叉验证
- 数据类证据需注明时间范围、采样方法、统计口径
- 引用法条需标注法律名称、条款号、生效日期

### 观点/策略类争点
- 需标明推理前提与假设条件
- 需列出反面论据（steel-man）
- 置信度标注：高(>0.8) / 中(0.5-0.8) / 低(<0.5)

### 证据分级
| 等级 | 类型 | 示例 |
|------|------|------|
| A | 一手数据/官方文件 | 财报、法律条文、监管公告 |
| B | 权威二手来源 | 学术论文、行业白皮书 |
| C | 专家意见/经验判断 | 从业者访谈、分析师观点 |
| D | 推测/未验证信息 | 市场传闻、未证实消息 |

## 质证要点

### 逐条质证清单
1. 来源可靠性：是否为一手来源？是否有利益冲突？
2. 时效性：数据/观点是否过时？
3. 完整性：是否存在选择性引用（cherry-picking）？
4. 逻辑链：前提->推理->结论是否自洽？
5. 可证伪性：是否提出了可被反驳的具体预测？

### 常见质证角度
- 样本偏差：数据是否覆盖全貌
- 因果混淆：相关性 ≠ 因果性
- 幸存者偏差：是否只看成功案例
- 锚定效应：是否被初始数据锚定
