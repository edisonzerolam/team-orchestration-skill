# 争点拆解模板

## 争点拆解框架

### 第一步：议题定性
- 事实判定型（是/否、真/伪）→ 适用投票制
- 价值权衡型（优劣、取舍）→ 适用辩论+裁决制
- 方案设计型（如何做）→ 适用混合型

### 第二步：争点分层
```
核心争点（1个）
├── 子争点 A（事实层）
│   ├── 证据 A1
│   └── 证据 A2
├── 子争点 B（逻辑层）
│   ├── 前提 B1
│   └── 推理 B2
└── 子争点 C（价值层）
    ├── 立场 C1
    └── 立场 C2
```

### 第三步：角色分配
| 争点类型 | 正方任务 | 反方任务 | 中立任务 |
|----------|----------|----------|----------|
| 事实层 | 举证支持 | 举证反驳 | 验证双方数据 |
| 逻辑层 | 构建推理链 | 寻找逻辑漏洞 | 评估推理强度 |
| 价值层 | 阐述价值主张 | 提出替代价值 | 比较权衡 |

### 第四步：收敛判定
- 连续两轮无实质变更 → 收敛
- 各方置信度差异 < 0.15 → 收敛
- 达到最大轮次 → 强制收敛

## 常见争点模式

### 投资分析类
- 核心：标的价值判断
- 子争点：基本面 / 估值 / 催化剂 / 风险

### 法律合规类
- 核心：行为合法性判定
- 子争点：法条适用 / 事实认定 / 法律后果

### 技术方案类
- 核心：方案可行性与最优性
- 子争点：技术可行 / 成本效益 / 风险评估
