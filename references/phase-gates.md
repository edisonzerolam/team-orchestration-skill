# 终审审核关卡（Phase Gates，v3.1）

> 对应 SKILL.md §3-C 终审：终审意见书交付用户前须通过以下关卡。

## G1 争点覆盖
- [ ] 核心争点与全部子争点均有裁决结论（采信 / 部分采信 / 排除）

## G2 举证完整性
- [ ] 每方举证均已回灌并完成质证（默认 1 轮，最多 2 轮）
- [ ] 质证记录标注「变与不变」

## G3 裁决理由
- [ ] 每条裁决标注采信/部分采信/排除 及理由（终审禁止引入新论点）

## G4 可信度门槛
- [ ] 意见书标注可信度 = 最薄弱证据的可信度

## G5 产物契约
- [ ] 终审意见书符合 SKILL.md 终审意见书最小契约（章节结构 + 归档路径）

## 不通过处理
- 任一关卡 FAIL → 回退至对应环节修正，禁止带关卡未过直接交付。
