# 终审审核关卡（Phase Gates，v3.1）

> 对应 SKILL.md §3 五阶段流程（C 质证 / D 一审 / E 二审终审）：二审终审意见书交付用户前须通过以下关卡。

## G1 争点覆盖
- [ ] 核心争点与全部子争点均有裁决结论（采信 / 部分采信 / 排除）
- [ ] 每条子争点（立案时拆出的 2-5 条）在终审意见书「逐条裁决」表中都有对应行（v3.5 · P1-2 完整性门禁）
- [ ] 遗漏/NA 子争点须显式标注并说明原因（v3.5 · P1-2）

## G2 举证完整性
- [ ] 每方举证均已回灌并完成质证（默认 1 轮，最多 2 轮）
- [ ] 一审判决书已回灌并完成修订（固定 1 轮，含判决书+他方产物）
- [ ] 质证与回灌修订记录标注「变与不变」
- [ ] 终审前置门禁：全部子代理回声已收集完毕或已终止确认（`list_agents` 无运行中）（v3.8 · TC-20260816-3）

## G3 裁决理由
- [ ] 每条裁决标注采信/部分采信/排除 及理由（二审终审禁止引入新论点，以一审修订产物为界）
- [ ] 每条裁决理由非空且含五维 rubric 维度引用（依据充分性/来源独立性/论证自洽/与质证一致/反证回应）（v3.5 · P0-1/P1-2）
- [ ] 回退重审合规：同一子争点回退 ≤1 次，重审次数已写入案卷 `cross_exam` 字段（v3.5 · P0-1）

## G4 可信度门槛
- [ ] 意见书标注可信度 = 最薄弱证据的可信度

## G5 产物契约
- [ ] 二审终审意见书符合 SKILL.md 终审意见书最小契约（章节结构 + 归档路径）
- [ ] 一审判决书已作为中间产物归档（03-一审/first-instance-verdict.md）

## 不通过处理
- 任一关卡 FAIL → 回退至对应环节修正，禁止带关卡未过直接交付。
