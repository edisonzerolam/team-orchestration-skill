# 终审审核关卡（Phase Gates，v3.1）

> 对应 SKILL.md §3 五阶段流程（C 质证 / D 一审 / E 二审终审）：二审终审意见书交付用户前须通过以下关卡。

## G1 争点覆盖
- [ ] 核心争点与全部子争点均有裁决结论（采信 / 部分采信 / 排除）

## G2 举证完整性
- [ ] 每方举证均已回灌并完成质证（默认 1 轮，最多 2 轮）
- [ ] 一审判决书已回灌并完成修订（固定 1 轮，含判决书+他方产物）
- [ ] 质证与回灌修订记录标注「变与不变」

## G3 裁决理由
- [ ] 每条裁决标注采信/部分采信/排除 及理由（二审终审禁止引入新论点，以一审修订产物为界）

## G4 可信度门槛
- [ ] 意见书标注可信度 = 最薄弱证据的可信度

## G5 产物契约
- [ ] 二审终审意见书符合 SKILL.md 终审意见书最小契约（章节结构 + 归档路径）
- [ ] 一审判决书已作为中间产物归档（03-一审/first-instance-verdict.md）

## 不通过处理
- 任一关卡 FAIL → 回退至对应环节修正，禁止带关卡未过直接交付。
